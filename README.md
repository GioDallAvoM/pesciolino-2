# Pesciolino 2.0

Un gioco in stile Duolingo per allenarsi alla prova di grammatica del CILS C2, «Analisi delle strutture di comunicazione»: dieci capitoli, dal B1 al C2, con lezioni, storie, allenamenti e una prova Leggendario per capitolo.

Gli esercizi sono originali: non è materiale ufficiale CILS. La guida, Prof. Gio, è un disegno.

Si gioca qui: https://giodallavom.github.io/pesciolino-2/
